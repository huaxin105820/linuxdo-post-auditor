# LINUX DO core rule snapshot

Source: https://linux.do/guidelines

Observed: 2026-07-27

Official page version observed: `2606081200`

This is a working audit snapshot, not an authoritative replacement. The current official guidelines and current category pinned posts take precedence.

## Hard boundaries

| ID | Audit rule | Default severity |
|---|---|---|
| CORE-001 | Do not submit AI-generated or AI-polished text. This skill must not create or improve publish-ready forum text. | BLOCKER |
| CORE-002 | Reject political discussion or evaluation of national policies or national leaders. | BLOCKER |
| CORE-003 | Reject pornography or sexually suggestive content. | BLOCKER |
| CORE-004 | Reject blood, violence, gambling, drugs, or organized-crime content. | BLOCKER |
| CORE-005 | Reject malicious provocation, antagonism, insults, defamation, public shaming, or dogpiling. | BLOCKER |
| CORE-006 | Reject rumors, fraud, black-market activity, and undisclosed malware or dangerous pages. | BLOCKER |
| CORE-007 | Reject malicious spam, meaningless content attacks, hidden characters, and abusive styling. | BLOCKER |
| LINK-001 | Reject encoded, transformed, shortened, encrypted, substituted, or otherwise obfuscated links used to evade review. | BLOCKER |
| PROMO-001 | Do not publish prohibited promotion, advertising, or unsolicited private-message advertising. | BLOCKER |

Keyword matching alone never proves a violation. When a term may appear in a technical, educational, or cautionary context, mark it for manual review instead of asserting a breach.

## Category and visibility

- Categories may have public, level-1, level-2, and level-3 child areas based on secrecy or sensitivity rather than technical difficulty.
- Use tags to refine broad categories.
- Permission-restricted or hidden categories may not appear for every account.
- Category names and requirements change. Require a current pinned-rule excerpt when a category is marked unverified.

## Source precedence

1. Current official guidelines.
